# Session metadata restore, pin order and focus mode (S098/S102/S143)
Pilot only. Explicitly enable recall of static destination pins within the browser tab session. Storage envelope contains a version, SHA-256 scope fingerprint, and allowlisted canonical destination IDs only. No record IDs, queries, drafts, credentials or clinical payloads. Restore requires a matching account/role/unit/permission fingerprint, existing route guards, and explicit confirmation; each reopened destination goes through the same dispatcher. Sign-out, expiry, scope mismatch and legacy rollback remove stored pins. No authorization is granted by the fingerprint.
Focus mode hides category navigation and pinned destinations, retains header and domain controls, preserves mounted content and restores keyboard focus. Pin order controls are accessible through options. Incident and risk pagination share the pure helper, retaining respective page sizes. Tests cover scope mismatch, forbidden destinations, malformed storage, actual reload and rollback; new CI evidence required. Draft recovery, live multi-pane state, full workspace rendering and production RLS/UAT remain open. No schema or dependency changes.
