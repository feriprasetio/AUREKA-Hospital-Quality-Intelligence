# S144 — incident multi-sort, ordered columns, view recall and advanced filters
Pilot only. Existing authorized incident list is filtered and sorted in memory; no schema, query permissions, formulas, mutation or export changes. Three explicit sort criteria with stable ID tie-break and nulls last; keyboard/touch buttons available without dragging. Identity is fixed first, unit and status cannot be hidden. Save/restore one in-memory view for the current mounted, scoped session; only columns, sort and page size, no record IDs or filter values stored. Scope/pilot changes clear the view. Additional date interval and exact incident type filters are opt-in and validated. Synthetic tests include 10,000 existing rows, multi-sort, ordering, filters and browser restore. This is not a universal persistent saved-view system or server-side query engine. CI and whole-product gates remain required.
