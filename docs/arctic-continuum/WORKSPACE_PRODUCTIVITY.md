# Arctic Continuum workspace productivity

Scope: opt-in shell command search from the already authorized navigation metadata, accessible modal using the existing controller, incident grid client-side pagination and whole filtered-list sort (25/50/100 rows), legacy unpaginated mode during global record search, and collapsible comparison analytics. All changes are presentation only; query, clinical computations, permissions, export and mutations are unchanged.

Limitations: paging here is client-side, not server-side pagination or virtualization. The existing backend reads the permitted rows first. This is a partial grid pilot, not full P3. Search indexes only canonical menu metadata, not cross-module objects. No new skills, mutations, relations, publication, or job controls are advertised. P0/P4–P7 full acceptance remains open.
