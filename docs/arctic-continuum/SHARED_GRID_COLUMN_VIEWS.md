# Shared column configuration and session views
Four read-only domains use one semantic table renderer and column configuration contract. Identity stays first and required fields cannot be hidden. Only presentation keys, sort and page size are recalled in memory during the mounted scoped view; no query, record ID or data is persisted. Hidden matching sort/search keys are removed; audit detail is display-only, never searched. SPM still avoids mixed-unit numerical sorting and retains its existing formula. Legacy table content remains the same outside pilot. Browser tests check actual visibility, reorder and restore. No schema, RPC, export, permission or clinical formula changes. Not full server-side universal grid or final v2 acceptance.
