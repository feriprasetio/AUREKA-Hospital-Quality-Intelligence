# Profile version review, reconciliation preflight and shared view undo
One package covering a fifth shared semantic grid (profile catalog), comparison of persisted profile versions from the existing authorized query, a fourth executable skill for aggregate reconciliation queue review, and bounded undo/redo of view configuration. Profile comparison requires exact code/year/unit, unique valid version numbers and visible anchor; it is not proof of parent-version lineage or an authorized rollback operation. Existing publish, retire, delete, mapping and warning-review actions retain their original RPC paths. Reconciliation preview uses counts returned in existing groups and never triggers a mutation; totals are not unique patients or completed changes. Undo/redo stores only presentation configuration in memory. Grouped catalog retains existing card rendering; no schema change, new dependency, new privilege, global clipboard or durable job service. Browser test uses isolated synthetic history and queue, not a production RLS/UAT result. Full v2 acceptance remains open.
