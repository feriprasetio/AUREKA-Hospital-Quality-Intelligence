# Risk review skill pilot (S105/S106/S119)
Executable read-only evaluation on a successfully refreshed authorized register snapshot, preserving current filters and the existing matrix/level calculation. A mismatch is flagged, never corrected automatically. The result includes aggregate level counts, active priority counts and missing data checks; it is a draft requiring review. Export is aggregate CSV using existing formula-safe encoding. No AI, no writes, no schema migration. Preflight blocks unverified data; scope/data changes invalidate prior results. Load sequence rejects late responses; cache separates account/role/unit scope. Synthetic tests cover pure computation and UI run without risk mutations. This is a domain pilot, not a universal Skills Library, persisted audit/job service or full Report Composer. Full production RLS, UAT and v2 acceptance remain open.
