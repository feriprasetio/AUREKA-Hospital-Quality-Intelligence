# Governance register and deterministic action review
S084 uses the shared semantic register with existing action dialogs and authorization, an optional grouped recommendation list and a fifth read-only skill in the canonical director/supervisory category. Counts, status and overdue use the same issuer filter as the register; orphan actions remain visible by established behavior and are explicitly disclosed. Pontianak date comparison. The report uses the existing aggregate review and export workflow; it cannot mutate or certify efficacy. Failed and stale reads do not expose prior-year rows. No backend changes, new privileges or production writes. Does not implement a durable jobs service, universal mutation workflow or restore.
