Master desain adalah dokumen AUREKA Arctic Continuum — Definitive Product Design & Engineering Specification v2.0. Baseline aktual ae8c13875f6384e8e34020e266d5b8a15bb91e3f, sama dengan [build GitHub Pages](https://github.com/feriprasetio/AUREKA-Hospital-Quality-Intelligence/actions/runs/46031252842). ## Inventaris dan sumber kebenaran

- [Peta 145 layar](SCREEN_TRACEABILITY_V2.md) menghubungkan katalog dengan implementasi, konteks rute, atau usulan. Seluruh 145 gambar unik dicocokkan terhadap katalog. Desain visual menetapkan prioritas data, aksi, dan keadaan layar. Kolom dan angka mockup bersifat ilustratif.
- Temuan scanner checkout mencakup 775 file tracked, 683 file sumber yang dibaca, dan 1.767 referensi statis. Di antaranya 126 nama RPC literal, 57 nama relasi, 154 nama kandidat operasi, 621 nama kandidat objek SQL, dan 38 referensi stylesheet. Nama kandidat dapat mencakup migrasi historis dan pengulangan. Jalankan node scripts/arctic-continuum-discovery.mjs untuk indeks path dan baris. Panggilan dinamis dan enforcement per operasi perlu verifikasi terpisah.
- Navigasi berjalan dari [registry](../../lib/aureka/module-registry.ts), [parser hash](../../lib/aureka/workspace-route.ts), dan [orkestrasi workspace](../../components/HomeClient.tsx). Terdapat 12 entri registry, delapan kategori resmi, delapan role internal, portal anonim, dan dua entry point halaman fisik. Jaga pengecualian Dewas untuk Realcost agregat dan kepemilikan terpisah di modul teknis bersama.
- Formula dan ekspor harus ditelusuri melalui [indikator](../../lib/aureka/indicator-engine.ts), [Clinical Pathway](../../lib/aureka/clinical-pathway-metrics.ts), [Realcost](../../lib/aureka/realcost-engine.ts), [OPPE](../../lib/aureka/oppe-engine.ts), [Risiko](../../components/RiskManagementWorkspace.tsx), [XLSX episode](../../lib/aureka/patient-episode-workbook.ts), dan [ekspor asesmen](../../lib/aureka/individual-assessment-export.ts). Ini indeks awal titik kontrol perhitungan. Golden fixture semua domain, identitas dan artefak PDF/XLSX memerlukan verifikasi per alur.
- Dependensi langsung di [package.json](../../package.json) adalah Next, React, React DOM, Supabase JS, ExcelJS Hardened, JSZip, dan PDF.js. Gunakan [lockfile](../../package-lock.json) dan workflow GitHub existing. Repo memuat 221 migrasi SQL dan enam Edge Function.
